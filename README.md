# Starter Demo theme

Lightweight WordPress theme designed to be edited with Claude Code and deployed from GitHub.

- Design settings: `theme.json`
- Styles: `assets/css/main.css`
- Page sections (block patterns): `patterns/`
- Instructions for Claude: `CLAUDE.md`

On first activation the theme creates **Home** and **Contact** pages from the patterns,
sets Home as the front page and builds the primary menu.

Workflow: edit locally with Claude Code → `git push` to `main` → Hostinger deploys automatically.
